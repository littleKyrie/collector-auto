# 提案：清理 rotation_controller.py 中未使用的代码

## 概述

清理 `rotation_controller.py` 模块中未使用的方法和常量，简化代码库并提高可维护性。

## 背景

在代码审查过程中，发现 `rotation_controller.py` 中存在一些未使用的方法和常量：

- 这些方法是为 PLC 模式0（自动运行模式）设计的
- 当前系统只使用模式1（间隔运行+触发模式）
- 保留这些未使用的代码会导致：
  - 代码库膨胀
  - 维护成本增加
  - 容易引起混淆

## 问题

### 未使用的方法

1. `configure_parameters()` - 配置模式0的PLC参数
2. `confirm_parameters()` - 触发参数确认
3. `start_rotation()` - 启动自动运行
4. `wait_for_move_done()` - 等待移动完成
5. `stop_rotation()` - 停止运行

### 未使用的常量

1. `D_SET_MODEL_0_DELAY_TIMES` (316) - 模式0延时时间
2. `D_GET_AUTO_ACTION_POSITION` (308) - 读取间隔角度
3. `D_GET_AUTO_ACTION_VELOCITY` (312) - 读取运行速度
4. `S_SET_AUTO_ACTION` (57745) - 设置自动运行
5. `S_MOVE_DONE` (57747) - 移动完成信号（与 `coilReady` 重复）

## 目标

1. 删除所有未使用的方法
2. 删除所有未使用的常量
3. 保留兼容性常量（`S_COIL_*` 系列）
4. 确保代码清理后功能不受影响

## 范围

### 包含

- 删除未使用的5个方法
- 删除未使用的5个常量
- 保留所有被使用的方法和常量

### 不包含

- 修改现有功能逻辑
- 添加新功能
- 重构已使用的代码

## 影响

### 正面影响

- 减少代码量约 150 行
- 提高代码可读性
- 降低维护成本
- 避免开发者误用废弃的方法

### 风险

- 无风险：这些代码从未被调用
- 已验证：通过搜索确认整个代码库中无调用

## 成功标准

1. ✅ 所有未使用的方法被删除
2. ✅ 所有未使用的常量被删除
3. ✅ 现有功能测试通过
4. ✅ 代码库大小减少约 150 行
