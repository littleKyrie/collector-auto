# 360度旋转控制系统

基于Modbus-TCP协议的PLC旋转控制脚本，用于文物扫描系统的自动化360度旋转控制。

## 功能特性

- 支持指定旋转次数（自动计算每次旋转角度）
- 支持配置旋转速度（0-30°/s）
- 支持配置每次旋转后的停顿时间
- 使用PLC自动模式0（间隔运行+延时）实现稳定控制
- 实时进度显示
- 完整的错误处理和参数验证

## 系统要求

- Python 3.7+
- pymodbus 3.0+
- PLC设备（支持Modbus-TCP协议）

## 安装

```bash
pip install -r requirements.txt
```

## 使用方法

### 基本用法

```bash
# 使用默认参数（12次旋转，10°/s，3秒延时）
python main.py

# 24次旋转，每次15°
python main.py --rotations 24

# 速度5°/s，延时5秒
python main.py --speed 5 --delay 5

# 连接其他PLC地址
python main.py --host 192.168.1.100 --port 502

# 显示详细日志
python main.py --verbose
```

### 命令行参数

| 参数 | 缩写 | 默认值 | 说明 |
|------|------|--------|------|
| `--rotations` | `-r` | 12 | 旋转次数 |
| `--speed` | `-s` | 10.0 | 旋转速度（°/s），范围0-30 |
| `--delay` | `-d` | 3.0 | 每次旋转后的停顿时间（秒） |
| `--host` | - | 192.168.1.88 | PLC IP地址 |
| `--port` | `-p` | 502 | Modbus端口 |
| `--verbose` | `-v` | - | 显示详细日志 |

### 查看帮助

```bash
python main.py --help
```

## 工作原理

### 旋转控制流程

1. **参数配置**：计算每次旋转角度（360°/次数），写入PLC寄存器
2. **参数确认**：触发S400使参数生效
3. **启动运行**：触发S401开始自动运行
4. **监控完成**：检测S403上升沿信号，等待每次移动完成
5. **循环执行**：重复直到完成所有旋转次数

### 寄存器说明

| 寄存器 | 地址 | 说明 | 写入值 |
|--------|------|------|--------|
| D300 | 300 | 间隔运行角度 | 角度×100 |
| D304 | 304 | 运行速度 | 速度×100 |
| D316 | 316 | 延时时间 | 秒数 |
| D320 | 320 | 模式参数 | 0（间隔运行+延时） |
| S400 | 57744 | 确认参数写入 | 上升沿触发 |
| S401 | 57745 | 启动自动运行 | 上升沿触发 |
| S403 | 57747 | 单次移动完成 | 状态反馈 |

## 错误处理

### 常见错误

1. **连接失败**
   - 检查PLC电源和网络连接
   - 确认IP地址和端口正确
   - 检查防火墙设置

2. **参数错误**
   - 旋转次数必须为正整数
   - 速度范围：0-30°/s
   - 单次角度不能超过327.67°（INT范围限制）

3. **运行超时**
   - 检查PLC是否正常运行
   - 确认无报警或限位触发
